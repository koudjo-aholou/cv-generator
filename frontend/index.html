📄 Générateur de CV LinkedIn

Transformez votre profil LinkedIn en CV professionnel

Étape 1/3

📋 Comment ça marche ?

  1. Exportez vos données LinkedIn :
    • Allez sur LinkedIn → Paramètres et confidentialité
    • Cliquez sur Confidentialité des données
    • Sélectionnez Obtenir une copie de vos données
    • Choisissez les données à exporter (Profil, Postes, Formation, etc.)
    • Téléchargez le fichier ZIP et extrayez-le
  2. Téléversez les fichiers CSV ci-dessous
  3. Ajoutez une photo (optionnel) pour personnaliser votre CV
  4. Téléchargez votre CV en PDF
🔒 Confidentialité : Toutes les données sont traitées localement. Aucune information n'est sauvegardée sur un serveur.
